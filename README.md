# CatchSound

## 확장 프로그램 바로 설치하기

`feature/shared-ai-server` 브랜치를 내려받은 뒤 Chrome의 `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**로 `extension/` 폴더를 선택하세요. 공용 AI 서버 연결 정보가 포함되어 있어 토큰 입력이나 로컬 서버 실행이 필요 없습니다. 기존 설치를 업데이트했다면 확장 관리 화면에서 새로고침하세요.

공용 서버 운영 및 설치 상세는 [SHARED_AI.md](SHARED_AI.md)를 참고하세요.

보고 있는 일에 맞춰 탭 소리를 메인과 대기로 나누고, 대기 중인 소리를 대신 들어 중요한 순간을 알려 주는 크롬 확장입니다.

기능별 구현 범위와 확인 수준은 [read.md](read.md)에 정리했습니다.

다른 PC에서 로컬 서버 없이 레블업 AI를 쓰는 방법과 공용 서버는 [SHARED_AI.md](SHARED_AI.md)를 참고하세요.

## 실행

1. 프로젝트 루트 `.env`에 `OPENAI_BASE_URL`, `OPENAI_API_KEY`, `OPENAI_MODEL`을 설정합니다.
2. `python server/server.py`로 AI 서버를 켭니다. 기본 주소는 `http://127.0.0.1:8787`입니다.
3. `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**로 `extension/`을 고릅니다.
4. 소리가 나는 탭에서 아이콘을 눌러 연결하고, 맡기기 탭에서 프로필을 고릅니다.

연습용 중계는 `http://127.0.0.1:8787/demo/broadcast.html`, `?f=lecture`로 열 수 있습니다.
설치 없는 웹 체험은 `http://127.0.0.1:8787/`입니다.

## 구조

| 경로 | 역할 |
| --- | --- |
| `extension/background.js` | 탭 연결, 상태, 메인·대기 판단, 알림 |
| `extension/engine.js` | 소리 조절, 음성 인식, 순간 감지. 웹 체험과 공유 |
| `extension/lib/logic.js` | 크롬 API 없는 판단 로직 |
| `extension/popup/` | 툴바 팝업 화면 |
| `extension/content.js` | 페이지 위 호출 알림 카드 |
| `server/server.py` | 래블업 호출, API 키 보관, 웹 체험 페이지 제공 |
| `demo/` | 웹 체험과 모의 중계 |

배포할 때는 환경 변수 `AUDIO_FOCUS_TOKEN`을 설정하고, 맡기기 탭의 서버 주소와 데모 토큰을 바꿉니다.
크롬 음성 인식은 클라우드 방식이라 대기 탭의 음성이 인식 서비스로 전송됩니다.
화면 감지를 켜면 대기 탭의 화면 이미지가 판단 서버와 모델로 전송됩니다.

단축키는 `Control+Shift+K`(연결), `Control+Shift+→`(다른 소리에 집중), `Control+Shift+←`(복귀)입니다.

## 시험과 빌드

```
npm test
npm run build
```

`npm run build`는 `dist/catch-sound-extension.zip`을 만듭니다.

## frontend 통합 브랜치 확인

`codex/frontend-catch-sound`는 main의 CatchSound 엔진에 frontend의 A/B 화면과 탭 선택 흐름을 연결합니다.
`extension/popup/`이 공통 UI 원본이며 웹 체험도 같은 HTML 구조, CSS, UI 로직을 사용합니다.
웹은 샘플 음원을, 확장은 실제 Chrome 탭을 제어합니다. 서로 다른 UI를 따로 수정할 필요가 없습니다.

### 웹에서 먼저 확인

```
npm run preview
```

http://127.0.0.1:8788/ 에서 A/B 소리 선택 → 연결을 누릅니다.
샘플 음원의 음량, 좌우 방향, 음소거, 집중, 잠깐 확인, 복귀를 시험할 수 있습니다.
AI 설정이 없으면 AI 요청은 명확한 안내와 함께 503으로 응답합니다. 음성 인식은 프로필 선택 후 사용합니다.
실제 탭 캡처, 탭 이동, 소형 플레이어와 화면 감지는 Chrome 확장에서 확인해야 합니다.

### Chrome 확장에서 확인

1. chrome://extensions → 개발자 모드 → Load unpacked에서 **이 통합 브랜치의 extension 폴더**를 선택합니다.
2. 이전 CatchSound 확장은 꺼 두어 중복 실행을 피합니다.
3. 소리가 나는 웹 탭에서 확장 아이콘을 누릅니다.
4. 첫 번째 슬롯의 탭 선택 → 연결을 누릅니다. 다른 탭을 골랐다면 그 탭으로 이동한 뒤 아이콘을 다시 누릅니다.
5. 다른 소리 탭에서 두 번째 슬롯도 연결합니다. 더 필요하면 **＋ 탭 추가**로 슬롯을 늘리고 음량·방향·집중·복귀를 확인합니다.
6. 공용 AI 서버는 기본 연결 정보를 사용합니다. 별도 로컬 서버를 운영하는 경우의 설정은 `SHARED_AI.md`를 참고하세요.

선택 목록은 Chrome 세션 저장소에 보관되어 팝업을 닫아도 유지됩니다.
코드를 수정하면 확장 관리 화면에서 새로고침하고 기존 연결을 다시 연결하세요.

검증: `npm test`(순수 로직 및 실제 백그라운드 메시지 처리의 Chrome 모의 API 테스트), `npm run build`.
main 병합 전 실제 Chrome 탭 캡처와 AI 연결은 별도 확인이 필요합니다.

팝업은 소리 화면을 기본으로 표시합니다. 각 연결된 탭의 **알림 프리셋**에서 AI 자동 설정, 기본·내 프리셋, 알림 사용 안 함을 선택할 수 있습니다. 오른쪽 상단의 연보라색 **세부설정** 버튼에서 **기본 설정 / 프리셋**을 전환합니다. 기본 설정은 소리·알림·고급 설정으로 나뉘며, 프리셋에서는 AI 초안 또는 직접 작성으로 만들고 적용·수정·삭제할 수 있습니다. 기본 프리셋은 복사해서 수정합니다. 탭 목록은 클릭 즉시 선택되며, 순간 목록은 팝업에서 숨기고 기존 알림 처리는 유지합니다.

## 탭에 맞는 AI 알림 조건

탭을 연결하면 먼저 해당 탭을 스캔한 뒤 레블업 모델이 알림 조건을 만들고 바로 적용합니다.
유튜브는 현재 영상의 제목·설명·표시된 자막을, 일반 페이지는 제목·설명·제목 문구·본문 일부를 읽습니다.
입력 폼·편집 영역·내비게이션은 본문 수집에서 제외하며, 접근이 제한된 페이지는 안내와 함께 제목 기반으로 진행합니다.
영상 전체나 아직 재생하지 않은 장면을 미리 분석하는 기능은 아닙니다.
슬롯의 **알림 조건 확인·수정**에서 조건별 켜기·끄기, 문구 수정, 추가·삭제를 한 뒤 **저장하고 적용**을 누르세요.
자동 제안이 의도와 다르면 같은 화면의 **AI에게 원하는 알림 설명하기**에 요청을 적고 **요청 반영해 다시 만들기**를 누르세요.
예: “한화가 경기 중일 때 한화의 갱킹, 상대가 한화 라인에 갱을 올 때, 한화가 참여하는 한타만 알려줘. 일정 안내는 빼줘.”
요청을 페이지 제목·설명보다 우선하며, 생성한 조건은 즉시 적용됩니다. 요청은 해당 연결에 저장되어 자막 보완이나 재시도에도 유지됩니다.
소리 구성의 **알림 프리셋**에서 기본·내 프리셋을 고르거나 **알림 사용 안 함**으로 끌 수도 있습니다. 탭의 알림 편집 화면에서는 **프리셋으로 저장**해 재사용할 수 있습니다.

처음 30초 이후 자막이 120자 이상 모이면 최근 자막으로 한 번 보완합니다.
사용자가 저장한 조건은 자동 보완하지 않습니다. **AI로 다시 제안받기**는 기존 조건을 새 제안으로 교체합니다.
생성 실패 시 오류가 표시되고 직접 조건을 작성하거나 재시도할 수 있습니다. 기존 조건이 있으면 실패해도 유지합니다.
조건은 해당 연결에 저장되며, 연결을 해제하면 다음 연결에서는 새로 생성합니다.

자동 모드에서는 메인 탭에서도 내용 파악을 위해 음성을 인식하고, 알림은 대기 탭에서만 보냅니다.
탭 제목·사이트·읽은 설명·본문·표시된 자막과 보완 시 최근 음성 인식 자막 일부가 판단 서버와 레블업 모델에 전송됩니다.
음성 인식을 사용할 수 없어도 제목 기반 제안은 가능하지만 자막 기반 보완과 의미 감지는 제한됩니다.
자동 조건은 단어 일치나 소리 급등만으로 알리지 않고, 자막에 근거해 조건이 발생했다고 AI가 판단한 경우에 알립니다.

검증: `npm test`, `python -m unittest discover -s tests -p test_server.py`, `npm run build`.


## 집중 전환과 알림 (0.2.0)

- 집중 버튼과 전환 단축키는 선택한 소리의 메인 음량을 적용하고, 다른 소리는 대기 음량으로 내린 뒤 대상 탭과 창을 활성화합니다. 이전에 고정하거나 음소거한 상태가 집중 전환을 막지 않도록 해제합니다.
- Mac은 실제 Control 키를 쓰도록 `MacCtrl`로 지정했습니다. 기존 설치의 단축키는 자동으로 바뀌지 않을 수 있으니 chrome://extensions/shortcuts 에서 Control+Shift+K / → / ←를 확인하세요. 운영체제가 선점한 조합은 이 화면에서 다른 Control 조합으로 지정합니다.
- 페이지 알림은 ‘여기에 집중’, ‘나중에’ 두 버튼만 표시하고 자동으로 닫지 않습니다. 새 알림은 기존 카드를 교체합니다. 페이지 이동·새로고침 시에는 페이지 카드가 제거됩니다. 시스템 알림은 유지 요청을 보내지만 표시 시간과 버튼 지원은 운영체제에 따릅니다.
- 감지 즉시 최근 자막을 표시하고, AI 응답이 도착하면 같은 카드의 내용만 요약으로 갱신합니다. 닫힌 카드나 새 알림으로 교체된 카드에는 늦은 요약을 표시하지 않습니다.
- AI가 꺼져 있거나 응답이 잘못되면 ‘최근 자막’임을 명시해 발췌 내용을 제공합니다. 자막이 없으면 내용을 추측하지 않습니다. 실제 AI 요약에는 서버 주소, API 키, 모델명이 필요합니다.
- 검증: Chrome 모의 API로 버튼·단축키의 음량/탭 전환, 알림 수명과 교체, 비동기 요약 갱신 및 실패 대체 표시를 검사합니다. 실제 래블업 모델 응답은 별도 설정 후 검증해야 합니다.
