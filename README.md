# CatchSound

**여러 탭의 소리를 나눠 듣고, 낮춰 둔 탭에서 중요한 순간이 오면 알려 주는 Chrome 확장입니다.**

강의를 들으면서 경기 중계를 작게 틀어 두면, CatchSound가 중계를 대신 듣다가 중요한 장면에서 알림을 보냅니다. 알림의 버튼 하나로 그 탭의 소리로 넘어갈 수 있습니다.

## 심사위원 빠른 체험

기본 연결은 `크롬 확장 → Vercel 공용 중계 서버 → 레블업 API`입니다. 사용자 PC에서 서버를 켜거나 레블업 API 키를 입력할 필요가 없습니다. AI 기능은 공용 서버가 운영 중이고 배포된 접속 토큰이 유효해야 사용할 수 있습니다.

준비물: PC용 Chrome 139 이상, 인터넷 연결, 한국어 음성이 나오는 영상 2개

### 1. 설치

1. [최신 코드 ZIP](https://github.com/leewonjunlee-eng/InThon/archive/refs/heads/main.zip)을 내려받아 압축을 풉니다.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
5. 압축을 푼 폴더 안의 `extension` 폴더를 선택합니다. `manifest.json`이 바로 보이는 폴더입니다.

기존 설치를 업데이트할 때는 설치에 사용한 폴더의 코드를 갱신하고 확장 관리 화면에서 **새로고침**하세요. 열려 있던 영상 페이지도 새로고침한 뒤 다시 연결하세요. 서로 다른 폴더에서 설치한 CatchSound가 동시에 켜져 있다면 하나만 활성화하세요.

### 2. 탭 연결

1. 영상 탭을 2개 열고 둘 다 재생합니다.
2. 주로 들을 탭에서 `Ctrl+Shift+K`를 누릅니다. 이 탭이 **집중 탭**이 됩니다.
3. 다른 탭으로 옮겨 `Ctrl+Shift+K`를 누릅니다. 이 탭은 **대기 탭**이 되어 소리가 작아집니다.

Mac에서는 `Cmd`가 아니라 `Control`을 씁니다. 도구 모음의 CatchSound 아이콘을 눌러도 연결할 수 있습니다.

연결하면 AI가 탭 제목·설명·본문 일부와 표시된 자막을 참고해 알림 조건을 만듭니다. 접근이 제한되면 제목 중심으로 제안합니다. 영상 전체나 아직 재생하지 않은 장면을 미리 읽지는 않습니다.

### 3. 알림 받기

빠른 체험에는 곧 나올 단어를 키워드로 넣어 보세요. 직접 입력한 키워드는 AI 조건 판단과 별개로 음성 인식 자막에 등장하면 바로 알립니다. 입력란의 예시 단어는 자동으로 등록되지 않습니다.

1. CatchSound 아이콘을 누르고 대기 탭의 **알림 조건 확인·수정**을 누릅니다.
2. **키워드 설정**에 대기 탭 영상에서 곧 나올 단어를 입력합니다. 여러 개는 쉼표로 구분합니다.
3. **저장하고 적용**을 누릅니다.
4. 집중 탭으로 돌아가 영상을 보며 기다립니다.

대기 탭에서 그 단어가 인식되면 집중 탭 오른쪽 위에 알림 카드가 뜹니다. **여기에 집중**을 누르면 그 탭으로 이동하고 소리도 바뀝니다.

### 4. 더 확인할 기능

| 기능 | 해 보는 방법 |
| --- | --- |
| AI 맞춤 알림 | **알림 조건 확인·수정 → AI로 다시 만들기**에 원하는 상황을 문장으로 적습니다. 예: `한화가 참여하는 갱킹과 한타를 알려줘. 경기 일정 안내는 빼줘.` |
| 집중 전환과 복귀 | `Ctrl+Shift+→`로 다른 탭에 집중하고 `Ctrl+Shift+←`로 돌아옵니다. |
| 탭별 소리 조절 | 아이콘을 눌러 탭마다 음량과 왼쪽·양쪽·오른쪽 출력을 정합니다. |
| 방해 금지 | **세부설정**에서 켜면 알림이 뜨지 않고 페이지의 종 버튼에 모입니다. |
| 내 프리셋 | 알림 조건 화면에서 **프리셋으로 저장**하고 다른 탭에 다시 씁니다. |
| 감지 상태 | 페이지 안의 CatchSound 상태바를 펼치면 탭별 감지 상태와 마지막 음성 인식 시각이 보입니다. |

자동 조건은 이후 모인 음성 인식 자막으로 보완될 수 있습니다. 직접 저장한 조건은 자동 보완하지 않으며, AI 재생성에 실패해도 기존 조건을 유지합니다.

**튜토리얼**: 처음 열면 연습 화면이 나옵니다. 팝업 왼쪽 위의 CatchSound 로고를 누르면 다시 볼 수 있습니다.

### 알림이 안 올 때

| 증상 | 확인할 것 |
| --- | --- |
| 알림이 전혀 없음 | 알림은 **대기 탭**에서만 옵니다. 대기 탭 영상이 재생 중이고 **알림 프리셋**이 `알림 사용 안 함`이 아닌지 확인하세요. |
| 키워드에 반응하지 않음 | 음성 인식은 한국어만 지원하고, 받아쓰기가 틀리면 놓칠 수 있습니다. 상태바에서 마지막 음성 인식 시각을 확인하세요. |
| `조건 생성 실패`가 표시됨 | [서버 상태](https://catch-sound-ai.vercel.app/health)에서 `"aiReady":true`인지 확인하세요. 조건은 직접 입력해도 됩니다. |
| 서버 접속 토큰 오류 | 최신 코드를 받아 설치 폴더를 갱신하고 확장을 새로고침하세요. 최신 코드에서도 계속되면 서버 운영자가 배포된 접속 정보와 서버 설정을 확인해야 합니다. |
| 연결이 안 됨 | `chrome://` 같은 브라우저 내부 페이지는 연결할 수 없습니다. 일반 웹페이지에서 시도하세요. |
| 단축키가 안 먹음 | `chrome://extensions/shortcuts`에서 키가 지정되어 있는지 확인하세요. 다른 프로그램이 같은 키를 쓰면 바꿔야 합니다. |
| 코드를 받은 뒤 동작이 이전과 같음 | `chrome://extensions`에서 새로고침한 뒤 탭을 다시 연결하세요. |

## 동작 방식

```text
탭 소리 ─ 캡처 ─┬─ 음량·좌우 조절 ─ 스피커
                └─ Chrome 음성 인식 ─ 자막 ─┬─ 키워드 일치 ─ 바로 알림
                                            └─ 조건 판단 ─ Vercel 중계 서버 ─ 레블업 모델 ─ 알림과 요약
```

- **키워드**: 사용자가 입력한 단어가 들리면 AI 판단 없이 바로 알립니다. 받아쓰기가 조금 틀려도 찾습니다.
- **AI 판단**: 대기 탭의 최근 자막을 5초마다 살펴 알림 조건에 맞는지 판단합니다.
- **소리 변화**: 소리가 갑자기 커지면 이어지는 자막까지 함께 AI가 판단합니다. 소리만으로는 알리지 않습니다.
- **화면 변화 감지**: 엔진에 구현되어 있지만 기본값은 꺼짐이며 현재 팝업에는 활성화 메뉴가 없습니다. 개발자가 설정을 활성화하고 탭을 다시 연결하면 화면 변화가 클 때 캡처 이미지를 AI로 보내 판단합니다.
- **요약**: 알림에는 최근 자막을 먼저 보여 주고, AI 요약이 도착하면 같은 카드를 갱신합니다. AI 요약에 실패하면 `최근 자막`임을 표시합니다.

## 데이터와 보안

- 탭의 음성은 Chrome 음성 인식 서비스로 전송됩니다.
- 탭 제목, 사이트 주소, 페이지 설명과 본문 일부, 표시된 자막, 음성 인식 자막은 공용 서버를 거쳐 레블업 모델로 전송됩니다. 입력 폼과 편집 영역의 내용은 읽지 않습니다.
- 화면 감지를 켠 경우 캡처 이미지도 판단 서버와 모델로 전송됩니다.
- 자막은 메모리에 최근 30분만 보관하고, 탭 연결을 해제하면 지웁니다.
- 레블업 API 키는 Vercel 환경변수에만 있습니다. `extension/server-config.js`의 토큰은 공용 서버 접속용 공개 값입니다.
- 공용 서버 호출 제한은 IP·프로세스별 분당 180회입니다. 여러 서버 인스턴스에 걸친 전역 제한은 아닙니다.

## 알려진 한계

- 음성 인식 품질은 Chrome에 달려 있습니다. 함성이 크거나 말이 빠른 구간에서는 틀릴 수 있습니다.
- AI가 고른 조건은 영상에 따라 범위가 달라질 수 있습니다. 놓치면 안 되는 단어는 키워드에 직접 넣으세요.
- 페이지 알림 카드는 Chrome 안에서만 보입니다. 카드를 넣을 수 없는 페이지에서는 시스템 알림을 사용합니다.
- 장시간 연속 실행의 안정성은 측정하지 않았습니다.

## 개발자용

확장 테스트에는 Node.js가 필요합니다. 서버 개발·테스트에는 Python 3.12~3.14를 사용합니다. 확장 설치만 하는 사용자는 둘 다 필요하지 않습니다.

```bash
npm test                                          # 확장 테스트
pip install flask==3.1.3                          # 공용 서버 테스트에 필요
python -m unittest discover -s tests -p "test_*.py"  # 서버 테스트
npm run build                                     # dist/catch-sound-extension.zip 생성
```

**로컬 AI 서버**: 프로젝트 루트 `.env`에 `OPENAI_BASE_URL`, `OPENAI_API_KEY`, `OPENAI_MODEL`을 넣고 `python server/server.py`를 실행합니다. 주소는 `http://127.0.0.1:8787`입니다. 변수 이름만 OPENAI이고 실제 호출 대상은 레블업입니다. 서버를 켜는 것만으로 확장 연결이 바뀌지는 않습니다. 현재 팝업에는 서버 변경 메뉴가 없으므로 개발 시 별도 연결 설정이 필요합니다.

**웹 미리보기**: `npm run preview`를 실행하고 `http://127.0.0.1:8788/`을 엽니다. Windows에서 `python3` 명령이 없으면 `python server/server.py --allow-no-ai --port 8788`을 실행하세요. 샘플 음원으로 UI를 확인할 수 있고, 실제 탭 캡처는 확장에서만 됩니다. 연습용 중계는 `/demo/broadcast.html`과 `/demo/broadcast.html?f=lecture`입니다.

| 경로 | 역할 |
| --- | --- |
| `extension/background.js` | 탭 연결, 집중·대기 상태, 알림 |
| `extension/engine.js` | 소리 조절, 음성 인식, 순간 감지 |
| `extension/lib/` | 판단 로직과 서버 통신 |
| `extension/popup/` | 팝업 화면과 튜토리얼 |
| `extension/content.js`, `inbox.js`, `status-bar.js` | 페이지 위 알림 카드, 모아둔 알림, 상태바 |
| `server/server.py` | 레블업 호출과 프롬프트 |
| `app.py`, `api/index.py` | Vercel 공용 중계 서버 |
| `demo/` | 웹 미리보기와 연습용 중계 |

공용 서버 운영은 [SHARED_AI.md](SHARED_AI.md)에 있습니다. [read.md](read.md)는 초기 구현 기록이라 현재 화면과 다른 부분이 있습니다.
