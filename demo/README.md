# Audio Focus — 프론트엔드 데모

`index.html`을 브라우저에서 열면 바로 사용할 수 있습니다. 서버·빌드·패키지 설치가 필요 없습니다.

## 파일

- `index.html`: 페이지 구조
- `styles.css`: A/B 디자인과 반응형 레이아웃
- `app.js`: 예시 탭 목록과 화면 상태 전환

## 눌러볼 수 있는 기능

- A/B 슬롯 → 탭 목록 → 선택 확정 → 슬롯 연결
- 다른 슬롯에서 선택한 탭의 중복 선택 방지
- 볼륨·좌우 방향·듣기 음소거
- 집중 전환·잠깐 확인·이전 설정 복귀
- 연결 해제·재연결·선택 삭제
- 상태 전환 버튼 없이 빈 슬롯 → 탭 선택 → 선택 완료 → 연결 → 조절 화면으로 진행

모든 동작은 페이지 내부 상태만 변경합니다. 실제 Chrome 탭 열람·캡처, 오디오 처리, 단축키 및 백엔드는 없습니다. 새로고침하면 처음 상태로 돌아갑니다.

## 확장 프로그램 화면으로 사용

이 파일들은 확장 프로그램의 팝업 UI에도 활용할 수 있습니다. 이후 `manifest.json`의 `action.default_popup`을 `index.html`로 지정하고, `app.js`의 상태 변경을 확장 메시지와 연결하면 됩니다. 일반 웹 페이지와 달리 실제 탭 캡처에는 별도의 권한과 오디오 엔진이 필요합니다. 이번 폴더에는 manifest를 넣지 않았습니다.

## 디자인

- 기존 A/B 와이어프레임의 카드 구성과 인디고 컬러 유지
- 최대 460px의 팝업형 화면
- 좁은 화면에서는 버튼을 세로 배치
- 실제 기능과 오해하지 않도록 데모 안내 표시
